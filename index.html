Research & Projects 🔬

Intelligent Agent Design and Deployment for Healthcare

Apr 2025 - Jun 2025
Project Lead

I independently designed and implemented a lightweight AgentOS framework for healthcare question answering, centered on extensible Plan, Tool, Memory, and Action modules. After analyzing the limitations of existing frameworks such as LangChain in modular decoupling, execution control, and multi-agent collaboration, I extended the framework with inter-agent message passing and shared context. At the retrieval layer, I built a medical knowledge base with hybrid BM25 sparse retrieval and dense vector retrieval, used RRF fusion to improve recall for low-frequency medical terminology, and introduced query decomposition, Chinese medical synonym expansion, and bge-reranker-v2-m3 two-stage reranking. The reasoning workflow uses a hierarchical Coordinator with four specialist agents for symptom analysis, risk assessment, recommendation generation, and safety validation, plus a Self-Reflection mechanism to reduce hallucination risk and improve answer reliability.

Heterogeneous Resource-Aware Distributed Agent System

Jul 2025 - Dec 2025
Co-author

As a co-author of a SC 2026 accepted paper, I contributed to Maze, an open-source distributed system for agent workloads that has received 600+ GitHub stars. The system addresses coarse scheduling granularity, inefficient heterogeneous resource utilization, and severe resource contention in existing frameworks such as AutoGen. It refines scheduling granularity from the agent level to the task level, compiles complex agent workflows into DAGs with GPU, CPU, and I/O resource constraints, and introduces a HACS scheduling algorithm for resource-aware execution. On a 32-node A100 cluster, Maze achieved up to 6.2x throughput improvement, 71.2% lower P95 tail latency, and over 2x higher GPU memory utilization. Under dynamic workflows, P95 latency was reduced by 22.3% compared with Ray and 47.8% compared with AutoGen. I was primarily responsible for external API design and standardization, including workflow creation, task registration, and resource semantic declarations, and I conducted systematic benchmark evaluations on GAIA, tau-bench, and OpenAGI.

MotifAgent: Structure-Semantic Separation for Tool-Calling LLM Agents

Mar 2026 - Present
Co-first Author

As a co-first author of a SIGOPS ATC 2026 accepted paper, I proposed MotifAgent, an algorithm-system co-design framework for tool-calling LLM agents. At the algorithmic level, MotifAgent separates reusable and verifiable execution structures from step-by-step LLM decision making, allowing the runtime to execute stable control flow while the LLM focuses on semantic uncertainty. At the system level, it exposes structural information from agent execution to the LLM serving backend to improve scheduling, cache retention, and end-to-end service efficiency. I conducted systematic evaluations on APIBank, tau-bench, and AppWorld. Compared with ReAct-style agents, the framework preserves task effectiveness while substantially reducing LLM calls and token consumption, and service replay experiments show improved tail latency and task-level goodput.
